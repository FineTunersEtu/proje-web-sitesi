Supervisor: Assoc. Prof. Dr. Yücel Çimtay

About the Project

ADVIS is an end-to-end intelligent traffic surveillance platform that automatically detects traffic accidents, interprets accident scenarios using a multimodal LLM, performs license plate recognition, and generates structured forensic reports — all within a triggered pipeline architecture.

LSTM Autoencoder YOLOv8 + ByteTrack EasyOCR Spring Boot Next.js WebSocket
